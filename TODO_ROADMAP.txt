[IMPORTANT — 현재 프로젝트의 핵심 한계]
============================

현재 Server는 Firebase가 연결되지 않은 경우
Memory Store로 동작합니다.

현재 개발환경:

Firebase:
OFF

Game Engine:
MOCK_GAME_ENGINE=ON

Database:
Memory Store

따라서 현재 상태는 Production 시스템이 아니라
기능 연결을 검증하기 위한 개발 Skeleton입니다.

실제 운영으로 넘어가기 전에 Firebase 및 실제 영속 데이터 저장,
원자적 잔액 처리, 정산 및 멱등성 처리가 반드시 필요합니다.

[코드작성 AI 작업 원칙]
===============

코드작성 AI에게 작업을 요청할 때 반드시 다음을 지킵니다.

1.

현재 TODO_ROADMAP.txt의 현재 진행 위치를 먼저 확인합니다.

2.

PROJECT_BASELINE.txt의 기준 Commit을 확인합니다.

3.

최종 기획서 v7.0 FINAL을 기능 기준으로 사용합니다.

4.

이미 구현된 기능을 다시 만들지 않습니다.

5.

새 기능 구현 전에 관련 기존 파일을 먼저 검사합니다.

6.

필요한 파일만 수정합니다.

7.

새로운 중복 구조를 만들지 않습니다.

8.

기존 API와 Socket 이벤트를 임의로 변경하지 않습니다.

9.

금액은 micro-USDT 정수로 처리합니다.

10.

잔액 변경은 Server에서만 처리합니다.

11.

최종 베팅 확정은 Server에서 검증합니다.

12.

Client에서 권한을 결정하지 않습니다.

13.

관리자/Dealer 권한은 Server에서 검증합니다.

14.

실제 Secret을 코드에 넣지 않습니다.

15.

.env.example을 변경하면 실제 코드의 환경변수 사용도 함께 확인합니다.

16.

새 기능 구현 후 기존 기능을 다시 테스트합니다.

17.

작업 완료 후 변경 파일 목록을 알려줍니다.

18.

테스트 결과를 알려줍니다.

19.

TODO_ROADMAP.txt의 완료 항목을 업데이트합니다.

20.

작업이 정상적으로 완료되면 Git Commit을 생성합니다.
